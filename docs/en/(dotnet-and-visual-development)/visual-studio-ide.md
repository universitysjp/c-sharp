## What is an IDE?
Integrated Development Environment bundling editor, compiler integration, debugger, designers, source control, testing tools, extensions.

## Key Features
- Solution & Project Management
- IntelliSense (code completion & quick info)
- Debugger (breakpoints, watch, immediate, visualizers)
- Designers (WinForms, XAML, SSRS, etc.)
- Git tooling (commit, branch, stash, PR review)
- Live Share collaboration
- Test Explorer (unit/tests running & coverage)
- Extensions marketplace

## Customization Tips
- Use Profiles (General / C# / Web)
- Keyboard mapping (e.g., ReSharper style)
- Theme + Font for readability
- Code Cleanup profiles

## Compare with VS Code
| Feature | Visual Studio | VS Code |
|---------|---------------|---------|
| Lightweight | ❌ | ✅ |
| Full GUI Designers | ✅ | Limited |
| Extensive Wizards | ✅ | Minimal |
| Extension Ecosystem | Large | Very Large |
| Deep .NET Integration | ✅ | Via extensions |

Use Visual Studio for heavy Windows / enterprise & designer tasks; VS Code for cross-platform editing & light tasks.
