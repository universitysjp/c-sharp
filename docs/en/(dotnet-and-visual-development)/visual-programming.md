## What is Visual Programming?
Visual Programming Languages (VPLs) let you build programs by manipulating graphical elements (blocks, nodes, diagrams) instead of writing only text code. They reduce cognitive load for novices and speed up Rapid Application Development (RAD).

## Goals of VPL
- Accessibility for beginners
- Progressive learning path (novice → intermediate → advanced)
- Component / block reuse
- Fast prototyping (RAD)

## Core Language Notions
| Term | Meaning |
|------|---------|
| Syntax | Valid shapes / connections (like grammar) |
| Semantics | What a block / diagram means (behavior) |
| Pragmatics | How context & intent affect meaning |

## Example Domains & Tools
| Domain | Examples |
|--------|----------|
| Educational | Scratch, Ardublock, AgentSheets |
| Multimedia / Creative | Blender Nodes, OpenMusic, AudioMulch |
| Games | GameSalad, Clickteam Fusion, FlowGraph (CryEngine) |
| Simulation / Data | DRAKON, Orange, Dynamo |
| BI / ETL | Alteryx, Ab Initio, IBM Cognos |

## When to Prefer Text Code over VPL
- Complex business logic branching
- Performance‑critical algorithms
- Large scale solutions needing version control diffs

Visual + textual approaches can coexist (e.g., designers + code‑behind in WinForms/WPF/Unity).
